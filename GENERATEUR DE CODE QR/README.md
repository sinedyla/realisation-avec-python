# Générateur de Code QR

Un script Python pour générer des codes QR à partir d'un lien ou texte.

## Installation

```bash
pip install qrcode[pil]
```

## Utilisation

```bash
python main.py
```

Entrez un lien ou du texte, et le code QR sera généré et sauvegardé en PNG.

## Prérequis

- Python 3.6+
- Bibliothèque `qrcode` avec support d'images (Pillow)

## Exemple

```
Input:  https://www.google.com
Output: votre_qrcode.png
```
